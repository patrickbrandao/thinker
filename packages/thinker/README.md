# thinker

This package exists to hold the canonical **Thinker release version**.

It contains no code. The real backend and frontend live in [`../backend`](../backend) and [`../frontend`](../frontend), and shared types in [`../shared`](../shared). The Docker image `tmsoftbrasil/thinker` bundles the built backend + frontend.

## What it's for

- **Changesets target**: `.changeset/config.json` ignores `thinker-backend`, `thinker-frontend`, and `thinker-shared`, so when contributors run `npx changeset` the only selectable package is this one. Always target `thinker` regardless of which files you actually changed — this is the single source of truth for "the version of Thinker as a whole".
- **Docker release version**: the release workflow reads the `version` field from this package's `package.json` and uses it to tag the image.
- **Changelog**: `CHANGELOG.md` here (auto-generated by changesets) is the unified release history. Entries up to `6.28.6` are inherited from Manifest.

## Adding a changeset

```bash
npx changeset
# → select "thinker"
# → choose patch / minor / major
# → write a one-line summary
```

Commit the generated file alongside your code.
