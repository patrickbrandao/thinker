# Política de segurança

## Reportando uma vulnerabilidade

Se você encontrou uma falha de segurança no Thinker, avise-nos de forma privada usando o **GitHub Private Vulnerability Reporting**:

[Abrir um reporte privado de vulnerabilidade](https://github.com/patrickbrandao/thinker/security/advisories/new)

**Nunca abra issues públicas para vulnerabilidades**, nem comente detalhes em PRs ou discussões públicas.

Inclua o máximo de detalhes possível: versão ou tag da imagem, passos para reproduzir, impacto potencial e qualquer contexto adicional. Não inclua chaves de API ou credenciais reais.

## Versões suportadas

Damos suporte de segurança apenas à **última versão 0.x** publicada. Corrigimos nela e publicamos uma nova versão; não há backports para versões anteriores.

## Créditos

O Thinker deriva do projeto [mnfst/llm-gateway](https://github.com/mnfst/llm-gateway) (licença MIT). Vulnerabilidades no código herdado também devem ser reportadas aqui, pelo canal privado acima.
