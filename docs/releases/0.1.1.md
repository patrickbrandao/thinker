# Thinker 0.1.1

Versão de correção com uma novidade no primeiro acesso.

## Instalação

```bash
docker pull tmsoftbrasil/thinker:0.1.1
```

Atualização a partir da 0.1.0: troque a imagem e reinicie. Não há migração nem mudança incompatível.

## Novo

- **`THINKER_SETUP_TOKEN` (#183):** o operador pode definir o token de setup do primeiro administrador (mínimo de 16 caracteres; gere com `openssl rand -hex 24`). Assim, dá para subir o serviço e enviar o token a quem vai concluir o `/setup`, sem consultar o log do container.
  - O token definido nunca é impresso no log. O log só avisa que o token vem dessa variável.
  - Ele vale em todas as réplicas e deixa de funcionar assim que o primeiro administrador existe.
  - Um valor com menos de 16 caracteres impede o boot.
  - Sem a variável, nada muda: o Thinker gera um token aleatório de uso único e o imprime no log.

## Observação

Se você copiar o token aleatório de um visualizador de logs que mostra as cores cruas (o Portainer, por exemplo), não leve junto o `[39m` do fim da linha. Para extrair o token limpo:

```bash
docker logs thinker 2>&1 | grep -o 'setup token: [A-Za-z0-9_-]*' | tail -1 | cut -d' ' -f3
```
